# MiraiPanel — Hardware

Fertigungsdaten für die MiraiPanel-Hardware (PCB + Gehäuse).

Teil der [MiraiPanel](https://github.com/Holzmusik/MiraiPanel)-Projektfamilie
— siehe dort für die Gesamtübersicht, sowie
[MiraiPanel-LCD](https://github.com/Holzmusik/MiraiPanel-LCD) (Firmware) und
[LoxBerry-Plugin-MiraiPanel](https://github.com/Holzmusik/LoxBerry-Plugin-MiraiPanel)
(Loxone-Bridge).

## Was hier reinkommt (und was nicht)

Dieses Repo enthält ausschließlich **fertigungsfertige Exportdaten**:

- `pcb/` — Gerber, Bohrdaten (Excellon), Bestückungspläne
- `gehaeuse/` — STEP/DXF für Fräs-/Druckteile, Blech-/Glaszuschnitte

**Nicht enthalten** sind die nativen Konstruktionsdateien (Altium-Projekt,
CAD-Quelldateien) — nur die zur Fertigung nötigen Exportformate.
